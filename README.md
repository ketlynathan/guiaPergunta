# GuiaPergunta

**GuiaPergunta** é uma aplicação web que permite aos usuários visualizar todas as respostas feitas para perguntas disponíveis. Desenvolvida com **JavaScript**, **Node.js**, **EJS** e **MySQL**, a aplicação oferece uma interface simples e funcional para gerenciar perguntas e respostas.

## 📋 Visão Geral

O **GuiaPergunta** é uma plataforma interativa projetada para permitir que usuários cadastrem perguntas e visualizem respostas associadas. Utiliza um banco de dados **MySQL** para armazenamento de dados e **EJS** para renderização dinâmica de páginas, garantindo uma experiência fluida e amigável.

## 🚀 Funcionalidades

- 📝 Cadastro e visualização de perguntas.
- 📋 Exibição de respostas associadas a cada pergunta.
- 🎨 Interface amigável renderizada com EJS.
- ⚙️ Backend robusto com Node.js.
- 💾 Armazenamento de dados com MySQL.

## 🛠️ Tecnologias Utilizadas

- **JavaScript**: Lógica do frontend e backend.
- **Node.js**: Ambiente de execução do servidor.
- **EJS**: Motor de templates para renderização dinâmica de páginas.
- **MySQL**: Banco de dados relacional para armazenamento de perguntas e respostas.

## 📦 Pré-requisitos

Para rodar o projeto localmente, você precisa ter instalado:

- [Node.js](https://nodejs.org/) (versão 14 ou superior)
- [MySQL](https://www.mysql.com/) (versão 5.7 ou superior)
- Um editor de código, como [VS Code](https://code.visualstudio.com/)
